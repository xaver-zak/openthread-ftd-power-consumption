# Power measurements of ESP32-H2, nRF52840 and nRF5340

This folder contains current measurements of the ESP32-H2, nRF52840 and nRF5340 while operating as routers in an OpenThread network. The raw measurement data is published alongside the paper.

The paper focuses on determining the current consumption of these MCUs in different radio states, primarily during the transmission interval at different TX power settings. Five UDP messages with a 122&#8239;B MAC frame size were sent periodically to establish the mean current draw during transmission for each TX power setting. Detailed tables of the processed current draw during the transmission interval are provided below for:

- [ESP32-H2](#esp32-h2)
- [nRF52840](#nrf52840)
- [nRF5340](#nrf5340)
